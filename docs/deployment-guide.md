# Deployment Guide

## Firebase Setup

1. Create a Firebase project.
2. Enable Email/Password in Firebase Authentication.
3. Create a Cloud Firestore database in production or test mode as appropriate.
4. Register a Firebase web app and copy its config values into `.env.local`.
5. Enable Firebase Storage for the project.
6. Enable Firebase Cloud Messaging for the web app and generate Web Push certificates.
7. Add `NEXT_PUBLIC_FIREBASE_VAPID_KEY` to the app environment using the public VAPID key from Firebase.
8. Install the Firebase Functions workspace dependencies with `cd functions && npm install`.
9. Deploy `firestore.rules`, `firestore.indexes.json`, `storage.rules`, and `functions` with the Firebase CLI.

Example deploy command:

```bash
firebase deploy --only firestore,storage,functions
```

## Local Development

```bash
npm install
npm run dev
```

For the Functions workspace:

```bash
cd functions
npm install
```

## Vercel Deployment

1. Push the repository to GitHub.
2. Import the project into Vercel.
3. Add the Firebase environment variables from `.env.example`.
4. Deploy the project.
5. Set `NEXT_PUBLIC_APP_URL` to the canonical production URL when you want Firebase email links to always point back to that domain.
6. Add `NEXT_PUBLIC_FIREBASE_VAPID_KEY` to the deployed environment.

## Firebase Authentication Domains

If email verification fails in production with an unauthorized continue URL error, add the deployed app domain to Firebase Authentication Authorized Domains. The continue URL generated by the app must match a domain Firebase allows, and the domain should also match `NEXT_PUBLIC_APP_URL` when that variable is set.

## Azure App Service Deployment

1. Keep `output: "standalone"` in `next.config.ts`.
2. Build with `npm run build` so `.next/standalone/server.js` is generated.
3. Package deploy artifact with this layout:
	- `server.js` at artifact root (copied from `.next/standalone`)
	- `.next/static` under artifact root
	- `public` under artifact root (if present)
4. Set App Service startup command to `node server.js`.
